Moffat Bay Marina

CSD 460 Capstone Team Project

A customer-facing booking website for a fictional marina on Joviedsa Island in Washington's San Juan Islands, built as a team capstone project. Visitors can browse the marina, register an account, sign in, and reserve one of 72 slips across three docks. Built with Jakarta EE, JSP, and MySQL using Agile/Scrum methodology with multi-environment deployment, and deployed as a live demo on Azure App Service with Azure Database for MySQL.

PalletIQ WIP

Side Project

A full-stack warehouse operations app covering the operational middle layer that most WMS projects skip: Pull, Put, Pallet and Location ID lookups, and a visual Empty Locations map.
