Featured Projects

FitIQ

Live v1.5.5 · Side project

A workout and progress tracker for a small household, installable as a PWA. The React app talks straight to Supabase and Postgres with no custom backend, so privacy lives in the database: Row Level Security on every table, plus ownership triggers that stop a row from pointing at someone else's data.

How it's verified: a two-account isolation test (188 checks) and Playwright end-to-end tests in GitHub Actions against a local Supabase stack.

PalletIQ

Active development Floor app v1.11.1 · Manager app v1.0.0

An independent warehouse inventory system, informed by ~9 years in inventory control at a Target distribution center and built on synthetic data. A React tablet floor app and an Electron manager app share one Express + Prisma + MySQL API and one package of TypeScript types, so a data-shape change is a compile error everywhere it's used.

How it's verified: a written test plan with API, database and Vitest unit suites, plus Playwright end-to-end suites for both apps (the desktop tests drive the built Electron app), all against an isolated Docker MySQL test database.

It runs locally on my Mac, so there's no live demo. The screenshots show both apps.

ScribeIQ

Stable v1.0.2 · macOS on Apple Silicon

An on-device call recorder and transcriber. It records the microphone and the call as two synced tracks, so my side of the conversation is labeled without guessing, and the FastAPI server owns the recording state machine. It integrates a small Swift helper built on Apple's ScreenCaptureKit; Whisper transcribes on the Mac after recording.

How it's verified: Python tests for track merging, the state machine, the recorder protocol and every API endpoint, Vitest tests for the UI, and a Playwright end-to-end suite.

Moffat Bay Marina

Live Team capstone · I was team lead

A marina slip-booking site built by a team of four in Jakarta EE, JSP and MySQL. As team lead I set up page contracts and role rotation. I built the Registration, Book a Slip and My Fleet pages and the Login and Edit User Info / Register a Boat back ends, owned database management after our shared initial design, and deployed the site to Azure App Service with Azure Database for MySQL.

The Azure instance sleeps when idle, so the first visit can take up to a minute to load.

Family Passport Map

Live v2.5.0 · Side project

Tracks which US states and countries each family member has visited, with a color per person, a side-by-side Compare view, and PWA install. React and Express with Prisma and SQLite, in Docker on my home server; sign in with Microsoft, Google, GitHub or a passkey, and each account's people and photos stay private.

No account needed for the guest demo: it runs in your browser with a made-up family, and nothing is saved.
