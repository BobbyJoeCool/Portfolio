PalletIQ

Active Development Floor app v1.9.0 · API v1.2.6 · Manager desktop app scaffolded

A full-stack warehouse inventory and pallet-tracking system built from 20 years of warehouse floor and retail management experience. It tracks inventory by location rather than by item, with a four-tier role hierarchy, field-level permission gating, and a tablet UI designed for hands-free scanning: numeric-first input, no blocking pop-ups, and every pallet and location ID a tappable link. Organized as a monorepo with a shared TypeScript types package, an Express + Prisma API on MySQL, the React floor app, and a manager-facing Electron desktop app in progress.

Highlights
  • Pull and Put (directed and manual) driven by label scans with independent verification paths
  • Pallet ID and Location ID detail screens, reachable from any reference in the app
  • Empty Locations aisle summary and visual zone-by-zone staging map
  • v1.9.0 milestone: Individual Rate of Productivity (IRP), Pull Request Query, and Container ID Inquiry with a per-record audit trail
  • Badge + PIN login issuing signed JWTs, reservation locking, and Playwright end-to-end tests

DragonLedger

Active Development DatabaseApp v2.0.0 · Heroes in early development

DatabaseApp

A desktop content manager that stores, searches, and edits D&D 5e and 5.5e content: spells, classes, races, backgrounds, conditions, items, monsters, and feats. Content is bulk-imported from the Open5e API or a compendium XML file, uploaded as JSON, or entered by hand, with each import kept under its own named source that can be refreshed independently. Built with React, Express, Prisma, and SQLite, and packaged as an Electron desktop app.

Highlights
  • Browse and filter 8 content types by source, edition, and type-specific attributes
  • Every entry flagged as 5e or 5.5e, with an edition toggle on Browse (v2.0.0)
  • Open5e import with live progress tracking over server-sent events
  • Additive-only compendium import that never overwrites edited entries
  • Homebrew copies and in-place corrections, with shared Zod validation between client and server

Heroes PRIVATE REPO

A D&D 5e 2024 character sheet and DM companion app for iOS and Android, built with React Native (Expo) and TypeScript. It is designed engine-first: game rules for ability scores, HP, combat, conditions, spells, inventory, and encounters are written as pure TypeScript modules before the UI, backed by an SQLite schema for character persistence. Heroes will use DatabaseApp's content and eventually replace it as the day-to-day app.

Family Passport Map

Live v2.3.0 · Microsoft sign-in and private accounts

A family-friendly web app for tracking which places you and your family have visited: all 50 US states, plus 195 countries on a world map you explore one continent at a time. Each family member gets their own color and profile picture, and their visits are tracked independently. Installable as a PWA for phone, tablet, and desktop.

Highlights
  • Interactive US and world maps: click a state or country to mark it visited
  • Compare view for side-by-side family member maps
  • List view with profile-picture icons and "n/50 states" and "n/195 countries" counters
  • Microsoft sign-in with private, per-account People (up to 10 per account)
  • Next up: Link and Join, so families can share and manage People together

TLDR Reader

Live v2.1.0 · New articles ingested daily

A personal web app for reading, flagging, and permanently saving articles from the TLDR newsletter, built for daily use on mobile and desktop. Article content is scraped from all 14 TLDR editions by a deterministic Node.js pipeline and published as static JSON, while per-user state lives in Azure Cosmos DB behind Microsoft sign-in.

Highlights
  • Browse This Week and Last Week by day and newsletter edition
  • Archive calendar: browse any past date with available articles
  • Flag articles to a Reading List; star to permanently save them

  • Planned: edition and date filters and keyword search for Saved Articles

Animated Spells

Released v1.0.0 · Foundry VTT module

A Foundry VTT module that automatically plays visual animations when spells from the official D&D 5.5e content packs are cast. It intercepts spell rolls and plays matching JB2A animations: projectiles fly from caster to target, area-of-effect templates fill with animated effects, and self-targeted buffs pulse on the caster's token. No manual macro setup required.

Highlights
  • Automatic spell-to-animation mapping via compendium UUIDs
  • Supports projectile, template, self, and emanation delivery
  • Covers five official content packs, each activating only when installed
  • Built on the Sequencer and JB2A animation APIs
