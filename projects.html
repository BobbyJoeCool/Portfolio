TLDR Reader

A personal web app for reading, flagging, and permanently saving articles from the TLDR newsletter. Issues are browsed by day across five sections — This Week, Last Week, Archive, Reading List, and Saved Articles. Deployed to Azure Static Web Apps with Microsoft authentication and Azure Cosmos DB for per-user state. Article content is scraped daily via an automated ingestion pipeline.

Highlights
  • Browse This Week and Last Week by day and newsletter edition
  • Archive calendar: browse any past date with available articles
  • Flag articles to a Reading List; star to permanently save them
  • Microsoft (Azure AD) authentication with per-user cloud state
  • Automated daily ingestion pipeline via scheduled scraper

Azure Static Page Host for TLDR Reader

PalletIQ WIP

A full-stack warehouse operations app covering Pull, Put, Pallet and Location ID lookups, and a visual Empty Locations map. Built from 20 years of warehouse floor experience with a four-tier role hierarchy, field-level permission gating, and a UI designed for hands-free scanning: numeric-first input, no blocking pop-ups, and every pallet and location ID a tappable link.

Core Functions
  • Pull — all pull types driven by label scan with two-path verification
  • Put — directed put-away with zone logic and manual put with safety checks
  • Pallet ID and Location ID detail screens, reachable from any reference
  • Empty Locations — aisle summary and visual zone-by-zone map
  • Reservation locking with server-side timeout cleanup

DragonLedger: Heroes

A D&D 5e 2024 character sheet and DM companion app for iOS and Android, built with React Native (Expo) and TypeScript. Designed engine-first — all game logic is implemented as pure TypeScript functions with full Jest test coverage before any UI is written. Features a full SQLite schema for character persistence, a RevenueCat-managed entitlement system (Free / Adventurer / Pro tiers), and an event-sourced state architecture designed for future local WiFi and cloud multiplayer sync via Supabase.

Highlights
  • HP, ability scores, movement, inventory, spell slots, and combat action economy engines
  • DM mode with encounter builder and initiative tracking
  • RevenueCat in-app purchase integration
  • Local WiFi and cloud multiplayer sync (in development)

Animated Spells — Foundry VTT Module

A Foundry VTT module that automatically plays visual animations when spells from the official D&D 5.5e content packs are cast. Intercepts spell rolls and plays matching JB2A animations — projectiles fly from caster to target, area-of-effect templates fill with animated effects, and self-targeted buffs pulse on the caster's token. No manual macro setup required.

Highlights
  • Automatic spell-to-animation mapping via compendium UUIDs
  • Supports projectile, template, self, and emanation delivery
  • Compatible with multiple official D&D content packs
  • Built on Sequencer and JB2A animation APIs
