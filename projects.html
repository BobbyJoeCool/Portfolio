PalletIQ

Active Development Floor app v1.11.1 · API v1.4.0 · Manager desktop app v1.0.0

A full-stack warehouse inventory and pallet-tracking system built from 20 years of warehouse floor and retail management experience. It tracks inventory by location rather than by item, with a four-tier role hierarchy, field-level permission gating, and a tablet UI designed for hands-free scanning: numeric-first input, no blocking pop-ups, and every pallet and location ID a tappable link. Organized as a monorepo with a shared TypeScript package for types and pure domain rules, an Express + Prisma API on MySQL, the React floor app, and a manager-facing Electron desktop app.

Highlights
  • Pull and Put (directed and manual) driven by label scans with independent verification paths
  • Pallet ID and Location ID detail screens, reachable from any reference in the app
  • Empty Locations aisle summary and visual zone-by-zone staging map
  • Individual Rate of Productivity (IRP), Pull Request Query, and Container ID Inquiry with a per-record audit trail
  • v1.10–1.11: architecture refactors into deep modules (reservation lifecycle, container lifecycle, location acceptance policy), a Printer table, and a rewritten e2e suite
  • Desktop app v1.0.0: Job/Function Assignment roster timeline with staffing forecast, Team Prod Summary, Location Setup, Prod Goal / Ramping / Daily Plan, a three-pane Audit Tool, and the Embedded Floor App
  • Badge + PIN login on the floor and password login on desktop, signed JWTs, reservation locking, and Playwright end-to-end tests for both apps (desktop tests drive the built Electron app)

ScribeIQ

Complete v1.0.1 · Runs entirely on-device · macOS on Apple Silicon

A private, on-device call recorder and transcriber for macOS. Record a call from Zoom, Teams, a browser, or any other app and get a speaker-labeled transcript with no cloud services, no subscriptions, and no audio leaving the machine. Instead of recording one mixed stream and guessing who said what, a native Swift helper records the microphone and the call as two separate, synced tracks, so it always knows which words are yours. A React + TypeScript interface in a native window talks to a local FastAPI server that owns the recording state machine.

Highlights
  • Captures the mic and one chosen app's audio with Apple's ScreenCaptureKit, with no virtual audio devices
  • MLX Whisper large-v3 transcription, Metal-accelerated on Apple Silicon
  • pyannote speaker identification on group calls; click a name to rename that speaker everywhere
  • Live timer, level meters, and job progress pushed over a WebSocket
  • Pause and resume with markers in the transcript, plus a History of every saved transcript

Voicewright

Active Development v1.0.0 · Runs locally on a Mac · Still improving

A local text-to-speech app that designs custom AI voices from a text description, then turns a tagged script into a finished audio file mixing emotions and sound effects, for example [angry] I hate you! {explosion}. Everything runs on the Mac with free, open-source models; the only network use is searching Freesound to fill the local sound library. A FastAPI backend runs model jobs in the background and serves a local web page.

Highlights
  • Voice design with Qwen3-TTS VoiceDesign: a neutral clip plus one preset per emotion
  • Speech and voice cloning with Chatterbox on MLX
  • Review and edit Voices take by take: regenerate, retune exaggeration and cfg, or roll back to an earlier take
  • Sound library: search Freesound, preview, and add sounds with their credit and license
  • Script editor with tag highlighting and a check that reports every problem at once, then renders one WAV with even volume
  • Saved Outputs keep a record of the Script, Voice, values, and every sound's credit
  • Real-model smoke test runs offline; QA pass checked all 61 user stories

FitIQ

Live v1.5.5 · Demo account live

A private workout and progress tracker for a household of 2 to 4 people. Plan routines, log every set on your phone as you go, and track weight, body measurements, and lifts over time. It is an installable PWA that costs $0 a month to run: React and Vite on GitHub Pages, talking straight to Supabase Auth and Postgres, with privacy enforced in the database through Row Level Security on every table.

Highlights

  • Workout history, personal records, and weight and measurement charts
  • Two-account RLS test on every table, plus Playwright E2E tests in CI against a local Supabase stack

ForkIQ

Early Development Foundation built · Working toward v1

Nutrition Tracker PRIVATE REPO

A personal nutrition and supplement tracker, the food-side companion to FitIQ. Log meals from a USDA FoodData Central search or an Open Food Facts barcode scan with the phone's camera, track water, and record vitamin and medication doses against a daily regimen, all on one Day screen with calorie, macro, and water goals. Designed to cost $0 a month on Azure Static Web Apps and Neon Postgres, with passkey login and a separate public demo that can never reach the real data.

So Far
  • npm workspaces monorepo: a pure TypeScript core, an Azure Functions API, and a React + Vite web app
  • Database migrations tested on PGlite, with a migrate script that refuses edited migrations and rolls back cleanly
  • Lint and build guards that keep the web app from importing the core past its contract
  • Typecheck, lint, test, and build on every pull request in GitHub Actions
  • Domain glossary and ADRs written before the features
